# Peepl

A private, personal "people log": remember everyone you meet, where you met them, and their story. This repo is a clickable prototype of the PRD's **people list**, **mindmap**, capture flow and person profile. (A map screen existed and was removed at the user's request.) Everything is private to the user; no social features.

**Keep this file up to date.** Whenever a design decision is made or changed, a feature is added, or a next step is finished, update the relevant section here in the same change, so work can continue on any device.

## Running it

- `npm install` once, then `npm run dev` → http://localhost:5173
- Check before committing: `npx tsc -b && npx eslint src`
- Stack: React 19 + TypeScript + Vite, plain CSS in `src/index.css`. No backend; data is sample data in code.

## Layout

- `src/Prototype.tsx` — the phone screen: top controls, current screen (Mindmap or Connections list), the ask bar at the bottom. Holds the tab, mindmap grouping, layers and toasts. It also makes people / moments from captures (`createPerson`, `addMoment`).
- `src/App.tsx` — wraps it in an iPhone 15 frame on desktop and scales the frame to fit the window. There is no side panel any more: the style playground was removed at the user's request, with its last settings (Frost glass, Sphere avatars; the Cream background has since been replaced by off-white) baked into the defaults.
- `src/screens/` — `ListScreen`, `MindmapScreen` (the people graph), `CaptureScreen` (add a person / moment), `AskScreen` (find someone), `ProfileScreen`. `src/lib/mindmapColors.ts` still holds what the dot colors can mean, but there is no UI for it now (always Relationship).
- `src/components/Keyboard.tsx` — the iOS keyboard (Figma "Keyboard", iOS 26 look) for the desktop frame only (under 600px the system keyboard is used). It types into whichever textarea has focus (`useKeyboardTarget`), slides up from the bottom, and `.has-kb` on `.phone` lifts `.flow-bottom` / `.sheet-bar` / toasts above it (`--kb-h`). Letters, 123 / #+= layers, emoji grid, shift (tap, double-tap lock, auto-capital), hold-to-delete, key-pop, a small word list for suggestions, return (sends), mic (starts the composer's voice).
- `src/components/` — `TopControls` (view toggle + Filters), `AskBar` (bottom), `Composer` (the shared input: type or scripted voice), `Wave`, `StatusBar`, `Icons`.
- **Icons come from the Figma** (frame `177:6074`, "1.1 Mindmap / Explore connections — Zoomed out", page "V1 flow – detailed"; user's call 2026-10-19): `MindmapIcon` (Material *hub*, filled, 20px), `ListIcon` (lines with bullet dots, 22px), `MicIcon` (24px, 1.87 stroke), `AddPersonIcon` (Material *person_add*, filled, 24px), `FilterIcon` (Material *tune*, filled, 20px), `ChevronDownIcon` / `ChevronUpIcon` (16px, 1.33 stroke). They live once in `Icons.tsx` and use `currentColor`, so every screen that uses them (top controls, Filters menu, ask bar, Composer in Add / Find / profile) picks them up. The iOS keyboard keeps its own system mic glyph.
- `src/lib/ask.ts` — `interpret()`: turns a find request into results / an action (rule-based stand-in for a model).
- `src/lib/forceGraph.ts` — hand-rolled force simulation for the mindmap (no dependency). `src/data/mockPeople.ts` — seeded generator of fabricated people (mostly social, some work, few family; each knows 1-3 others, max 5, a few know nobody); open `/?mock=200` (up to 500) to stress-test the whole app with that many.
- `src/data/people.ts` — 17 sample people (Ana Ruiz, a hardware engineer, and Jordan Lee were added for the pitch demo; Zara got a climbing note and Aisha invests in hardware) (each has a `knows` list of ids; links are symmetric). `src/lib/people.ts` — search matching and helpers.
- `src/lib/peopleStore.ts` — everyone in the app (sample people + people added with **+**, plus logged moments, to-dos and closeness), via `usePeople()`. Additions and changes are saved in `localStorage` (`peepl.people.v1`), never in mock mode. To reset to the sample people, clear the site's data in the browser (the reset button lived in the removed style panel; `resetPeople()` still exists).
- `src/lib/capture.ts` — the voice script text, typed-note parsing (`parsePerson`, `parseMoment`), `momentCandidates` (does a note read as a moment with someone you know?) and how a capture becomes a `Person` or `Moment`. Capture, Ask and profiles open as full-screen **layers** above the tabs (`layers` in `Prototype.tsx`; back / close pops the top one).

## Design decisions (agreed with the user)

**Visual style** (from the user's reference images: soft, clean, modern, light, pastel)
- Base is black and white: white background, near-black text (`--ink: #111113`), grey secondary text. Light and semibold weights are mixed for headlines (e.g. "Mindmap is **coming soon**").
- **Fonts:** Geist for everything (`--font-body`, and `--font-heading` for headings with `--heading-tracking: -0.04em`), Geist Mono for meta (`--font-mono`), set in `:root` and loaded from Google Fonts in `index.html`. **The serif (Instrument Serif) was dropped at the user's request**; heading sizes were scaled to ~82% when it went. Any new heading should use `var(--font-heading)` and `letter-spacing: var(--heading-tracking)`.
- **No gradient behind the mindmap and list** (per the Figma, user's call 2026-10-19): the drifting pastel "aura" orbs were removed. The phone sits on the plain off-white `--bg` (`#f4f4f4`, Figma `ground-100`) with the dot grid. The pastel auras still appear only in the Add / Ask flows (`.flow-aura`). These carry the Figma **Texture/Grain** noise (`--noise`: fractal noise at frequency 1.25 / 3 octaves, thresholded so about half the pixels are white at 80%), masked to the pastel orbs as in the Figma (`.flow-aura::after`, user's call 2026-10-19). The profile hero keeps its own subtler `--grain`.
- Glassmorphism uses **two looks** (both frosted translucent white: `backdrop-filter` blur, white edge, soft lavender-tinted shadow). The **top controls, ask bar and composer** use the "Frost" look (`--glass*`: blur 34 / saturate 150 / fill 0.78, strong fill 1.0, edge 0.92), picked in the old style panel and now fixed in `:root`. The **other glass items** — list cards, find results and profile sheet — use the `--glass-vivid*` set. **No beige anywhere** (user's call 2026-10-19): every screen, the profile, the flow base and the desktop backdrop use off-white `--bg` (`#f4f4f4`). The old cream `#f4efe7` and `--ground-200` beige `#e9e1d5` are gone. The "soft" round and pill buttons use the Figma light gray `--pressed` instead.
- **Avatars: circles with the Figma "Blob club" characters** (user's calls 2026-10-19). Each of the 18 sample people has one of the 18 *Original* blobs (frame "Blob club — 54 sticker collection", node `196:5644`, "Ask flow" page), whose full square photos are in `src/assets/blobs/*.jpg` (480px). `src/lib/blobs.ts` holds the person → blob map (`assigned`, roughly cool blues / greens for work, warm oranges for social, yellows / pinks for community; anyone added later gets one from a hash of their id) and each blob's colors: `soft` (avatar backdrop + profile aura, `avatarColors()`), and `base` / `mid` / `accent` / `deep` for the dark hero and new-person card (mint is the Figma's exact teal / gold; the others follow the same recipe). **The avatar follows the Figma "Profile" component** (node `190:13740`, variants list / results / map / create / hero): a circle with a 2px white ring, filled with a close crop of the photo (image ~2.6× the circle, centered; ~2.3× at 60px). Sizes: 40px list + search results, 36px mindmap pill (`avatar-sm`), 60px new-person card + profile hero (`avatar-lg` / `avatar-xl`). The 36 companion stickers aren't used.
- **Pressed and selected states are light gray** `--pressed` (`rgba(22,18,28,0.08)`, from the Figma): the active view button in the nav pill, the selected Filters menu item, and the press feedback on the view buttons, the Filters button and the menu items.
- **Dark buttons use the Figma night color** `--night` (`#1c1522`), not black (user's call 2026-10-19). This covers the focused group name, the `.round-button.ink` / `.pill-button.ink` buttons (Composer send, etc.), the "← Name" back pill, **Neither, add a new profile**, (the Ask result actions **Draft a message**… are now white glass pills, per the Figma "Profile" / results). The toast and the Ask thinking dots stay `--ink`, since they aren't buttons. The + button has a plain neutral shadow. The user removed its pastel glow.
- Desktop device frame is light silver, not black.
- Glass surfaces create a containing block for `position: fixed`, so any full-screen overlay opened from inside a glass element must be portalled into `.phone`.

**iOS feel**
- No visible scrollbars anywhere (global rule in `index.css`); it's a mobile app. Scrolling still works.
- Motion uses `--ios-spring` (UIKit-like spring curve). Buttons shrink on press (`scale(.92)`), rows dim and shrink slightly. Screens fade in on tab change and the search dropdown scales in from the top. All off for reduced motion.

**Figma "V1" flow (current design)** — figma.com/design/bV6DQFxu5SHuF6hE5NIDeb, page frames under the "V1" section (node 104:6248): Add person / Add moment, Find someone, Person profile, Mindmap, Connections. The prototype follows those frames; this replaced the older nav-with-Ask-mic version (Ask sheet, floating nav pill, search bar and the + / mic in the nav are all gone; they're in git history).

**Overall**
- **Top controls**: a glass pill top-left toggles Mindmap / Connections list; on the Mindmap a **Filters** pill top-right opens the **Group by** menu (None / City / Met at / Job, with a check on the current one). There is no search bar and no color filter any more (dot colors are always the relationship colors). **Both pills are 54px tall** (view buttons 42px in 5px padding; Filters button height 54px), shortened from 62px at the user's request. The selected view is shown by a **sliding gray blob** (`.view-blob`, Vince's change) that springs between the two buttons with a slight bounce and can be dragged; it is 42px and steps 44px (`STEP` in `TopControls.tsx`), so it must change with the button size.
- **Bottom ask bar**: a wide glass pill **"Ask me about people"** with a mic (tap the text to type, the mic to speak; both open the Find flow) and a round **add person** button on its right (opens the Add flow).
- Sizes are about 5% smaller than the first version. The user found 15% smaller too small.
- On desktop, the app sits in a light silver iPhone frame with a fake status bar (9:41, signal, Wi-Fi, battery), Dynamic Island, and home bar. On a real phone (under 600px wide) the frame and fake status bar are hidden. Use `var(--safe-top)` / `var(--safe-bottom)` for spacing, not `env()` directly.
- Inputs stay 16px so iPhones don't zoom in on tap.

**Connections list**
- Title "Connections", then one row per person, as the Figma "Profile" / list: 70px, white 0.85 glass, 20px corners, avatar, **name (16 medium) and job · city (13, muted)**, gray chevron. Sorted A–Z. Tapping a row opens the profile.

**Mindmap** (look C "glass", chosen by the user)
- Obsidian-style graph of everyone; no central "you" node. Links are the explicit `knows` lists on people (`linksOf` in `src/lib/people.ts`). Densely linked groups clump tighter (link strength grows with mutual neighbors).
- **Dots** use the Figma **aura fill** (`Aura/Work`, `Aura/Social`… styles, user's call 2026-10-19): a radial gradient in the design-system colors for how you know them — `--<context>-deep` at the heart (0–22%), `--<context>-core` at 55%, fading to `--<context>-wash` at the edge — with a light grain overlay (`.mm-node::after`), and white initials. **Blend auras** (Figma `Aura/Blend work–social` etc.) for people you know two ways: an optional `alsoContext` on a person adds `.mm-node.is-blend` — `context` deep at the heart → its core at 45% → `alsoContext` core at 80% → its wash at the edge. As in the Figma: Maya Chen social–family (her `context` changed from work to social to match), Aisha Khan work–social, Liam O'Connor community–work. **Size follows interaction** (`radiusOf`: logged moments + closeness), so people you've engaged with most are biggest. **Initials are hidden when zoomed out and fade in as you zoom in** (`--k` set on `.mm-world`, `.mm-node b` opacity). Links are a darker purple. The whole phone sits on the Figma **dot grid** (`--dots` in `:root`, dots at 11% ink, lightened from 16% at the user's request; the profile sheet has its own aura instead).
- **Group by** (Filters menu): a group pulls its people together and gets a soft pastel "territory" cloud with its name. Tap the name to isolate that group (everyone else fades); tap empty space to clear. Groups of one person stay ungrouped. `groupBy` lives in `Prototype.tsx` → `MindmapScreen`.
- Tap a node: the view zooms to center it with its direct connections in frame (the user can then pan freely). It lights up, direct connections dim to 55% and everyone else fades to about 8% (only first-degree links are shown). A fully round glass pill (Figma "Profile" / map) shows their avatar, name, job · city and a chevron; tapping the pill opens their profile (the old black **View** button is gone). Drag a dot to move it (only zoomed in past about 0.6x; zoomed out, dragging anywhere pans), drag background to pan, wheel / pinch to zoom, with rubber-band limits: zooming out past 85% of the "everyone in frame" zoom (or in past 3x) stretches with resistance, then springs back on release (pinch end, or 140ms after the wheel stops; `settle()` in `MindmapScreen.tsx`). The view auto-fits until the user pans, zooms or taps a person. Reduced motion settles instantly.

**Opening Add and Find: a circular reveal** (user's call 2026-10-19, after a Google Maps voice-search recording). Tapping the ask pill, its mic, the add-person button or a profile's "add mutual" grows the flow out of that button as a circle (`clip-path: circle()` from 24px to 135% at `--ox` / `--oy`, the tap point as % of the phone, set by `originOf` in `Prototype.tsx`; 0.7s, `cubic-bezier(0.4, 0, 0.2, 1)`, slowed so it reads clearly). Closing with the X (or Escape) shrinks the circle into the **X button** (`--cx` / `--cy`, measured in `closeGrow`), down to an X-sized circle, as in the recording (0.5s, same easing) before the layer is dropped.

**Add (the add-person button)** — `CaptureScreen`, "Tell me about a new person or moment"
- A full-screen pastel aura with a close button, the heading, and the shared **Composer** at the bottom ("Who did you meet?"). It opens focused for typing, but only as the circular reveal finishes, so the keyboard slides up once the screen has expanded (`waitForOpen` on the Composer: focus 150ms before the layer's `grow-circle` ends, i.e. about 0.55s in; shortened at the user's request, 2026-10-19). Find still focuses immediately; the mic "records" (**scripted demo**, no real mic): the Jordan Lee note appears word by word with a blue waveform, stop turns it into editable text, the arrow sends.
- One input for both. **A note about someone new** → "Creating a new profile for Jordan Lee…" → a dark card in the person's blob colors (Figma "Profile" / create: 60px ringed avatar, name 20 medium, job · city, "Met Oct 2026" in ground-300, white chevron; `cardBackground` in `lib/people.ts`); tap the card to open the profile. If you already have someone with that exact name (Jordan Lee is built in), their card shows instead of adding a duplicate. **A note about someone you know** (reads like a moment: "caught up with", "grabbed coffee"… and a name in it) → one match saves a moment straight away; two matches ask **"Which Jordan did you catch up with?"** with their cards ("Last updated Oct 2026") and a black **Neither, add a new profile** button (`momentCandidates`, Jordan Smith exists for this). Saving a moment opens that profile with the moment open, bumps closeness one step, adds any follow-up to the to-dos, and shows the **New moment saved** toast.

**Find (the ask bar)** — `AskScreen`, "Search for someone by…"
- Same aura / close / Composer ("Ask me about people"). Idle: three example cards (Interest, Occasion, Location; not tappable). Mic, typing or tapping an example card, then send: the request becomes the heading, a ~1.6s "thinking" state shows (changing status line + shimmering placeholder cards, `Thinking` in `AskScreen.tsx`), then result cards (they scroll behind the bar): avatar, name, job · city, a divider, **why** they match (17 light), and a white glass action pill (**Draft a message**, **Plan coffee**, **Draft intro**). The demo mic says *I want to find someone to go climbing with me* → Jordan Lee, then Zara Ahmed. Tapping the head opens the profile on top (back returns to the results). **Show all N in your list / on the mindmap** closes Find and narrows that screen; a glass pill above the bar ("climbing · 2", ×) shows it until cleared.
- `interpret()` in `src/lib/ask.ts` is a rule-based stand-in for a model (offline, no API key). It understands: add someone (hands off to the Add flow), log a moment / open a profile (opens the profile), catching up ("who haven't I talked to in a while"), richer answers (`buddy()`, `trip()`, `intro()`), and finding people by interests / work / places / how you know them. Drafts open **inline in the result card** (editable bubble + **Copy Text** / **Share**, like the Figma frames); copying or sharing ticks off the follow-up it answers on the profile and shows a toast.
- To swap in real AI later: replace `interpret()` with a call to Claude (needs an Anthropic API key and a small local server so the key isn't in the browser); speech could use the browser's speech recognition.
- **Jordan Lee is built into the sample people** (`src/data/people.ts`) so the climbing answer works without adding anyone first; a Jordan saved earlier in the browser is ignored as a duplicate (`peopleStore.build()`).

**Person profile**
- Opens from a list row, the mindmap pill, a mutual on another profile, an Add card, or a Find result. **It is always a full-screen page** with the back arrow and **⋯** on top (user's call 2026-10-19): the 80% half sheet with a drag handle was removed from every flow. It slides in from the right (`.layer.is-profile`) and back out on Back; from another profile it stacks, so Back returns one profile at a time.
- Hero as the Figma "Profile" / hero: the person's blob `base` color with three blurred shapes (mid top left, accent right, deep bottom left, `blur(23px)`), a 60px ringed avatar, name (20 medium), job · city (13), "Met Oct 2026" (13, ground-300). The scrolled bar fills with the same base color. Back and **⋯** buttons sit on a bar that fills in with their color and shows their name once you scroll past the hero. Then: a summary card (story + tags, no title; the "Summary" label was removed at the user's request 2026-10-19), **Things to do with Jordan** (tap a row to tick it off), **Where** (From / Met / Lives now), **Mutuals** (a dashed **Add** circle first, **View connections**), and **Moments** (collapsed; people without logged moments get a playable "First meeting" voice note made from their story; the open one gets a blue border; voice notes have a play / pause button, a waveform and a transcript that fills in as it plays).
- **Background: no dot grid** (user's call 2026-10-19). Behind the profile sits a soft pastel aura like the Add / Find flows, tinted with that person's own **avatar colors** (`avatarColors(id)` in `Avatar.tsx` → `--aura-a` / `--aura-b`, `.profile-aura` with the masked `--noise` grain). It stays put while the page scrolls.
- The bottom bar is the Composer, **"Add a moment"**: type, or the mic plays a scripted note about the person; send saves it with the **New moment saved** toast (black pill, lime check).
- **View connections** switches to the mindmap and focuses the person (`navFocus` in `Prototype.tsx`); a night-colored "← Jordan" pill gets back to the profile.
- `closeness` (1-3) on a person drives aura depth when set; otherwise depth still follows how recently you were in touch.
- New screens use only the foundation tokens in `:root` (plus `--grain`, `--shadow-float`, `--on-dark-*`), so a design system update there restyles them.

**Not carried over from the Figma yet** (V1 section audited screen by screen, 37 frames, all flows have a matching state): mutual captions exist (`mutualNotes` on a person; only Jordan has one), the mindmap zoomed-in node labels, and the Figma's AI-written moment titles (titles here are the first words of the note). 

**Removed at the user's request (don't bring back unless asked):** the map screen (globe, map looks, glowing pins, From / Met / Now filter chip and its bottom sheet) and the side panels (style playground, fonts, chip layouts). **Replaced by the V1 flow:** the search bar and its dropdown, the mindmap color filter, the bottom nav pill with the Ask mic, the Ask sheet, the "Try to cover" capture screen, and the Saved network screen.
