Owner: M1 manager (ios-core)   Builder: sonnet
Goal: `AIClient.parse(_ note:) async -> Draft?` exactly as in `.orchestration/briefs/M1-interface.md`. POST
`<base>/api/ai/parse` with JSON `{"text": note}`, `content-type: application/json`, 10 s timeout. Response JSON has string-or-null
fields name, does, company, from, lives, met, remember, goal, follow (see server/ai.ts `parse`). Validate like llmParse.ts:
name/company/from/lives kept only if they appear in the note (case-insensitive); title (Dr/Mr/Mrs/Ms/Prof) stripped from name;

"Wants to <x>" unless it starts with "want(s) to"; every field cut to 44 chars like `cut()`. Return nil on any failure
(offline, timeout, non-2xx, non-JSON). After a 503 or 404 stop asking for the rest of the process (return nil immediately).

via `INFOPLIST_KEY_`-style or an explicit `info.properties` entry in project.yml; read it with Bundle.main.

nothing more.
